# NOTES.md — Воркшоп по Git

## Шаг 2. Сравнение версий и поиск изменений

Выполненные команды:
- `git log --oneline --stat` — список коммитов с кратким хешем, сообщением и статистикой.
- `git diff HEAD~2 HEAD -- lab03/calc.py` — разница между файлом в HEAD~2 и текущим HEAD.
- `git show HEAD~1` — подробная информация о коммите HEAD~1 и его diff.
- `git log -S"def" --oneline -- lab03/calc.py` — поиск коммитов, где менялось количество вхождений "def".
- `git blame lab03/calc.py` — авторство последних изменений каждой строки.

Отличия:
- `git diff` показывает изменения между рабочей директорией и индексом или между коммитами.
- `git show` показывает информацию о конкретном коммите и его изменения.
- `git log` показывает историю коммитов.
- `git log -S` нашёл коммиты, где появлялась/исчезала строка "def".
- `git blame` показал, кто и в каком коммите менял строки.
