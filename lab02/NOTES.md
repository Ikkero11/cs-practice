# NOTES.md — Git и GitHub

## Рабочая папка, индекс и коммит

Рабочая папка - где мы правим файлы

Индекс - что мы подготовили к сохранению

Коммит - сохранённая версия в истории

## Git и GitHub

Git - локальная система контроля версий: хранит историю, ветки, слияния. Интернет не нужен.

GitHub - облачный сервис для хранения Git-репозиториев и совместной работы (issues, pull requests). Сам по себе системой контроля версий не является.

Различие: Git работает локально, GitHub — это удалённая платформа для Git-репозиториев.

## Использованные команды

- `git status` — показывает состояние рабочей папки и индекса: какие файлы изменены, какие добавлены в индекс, какие не отслеживаются.
- `git diff` — показывает различия между рабочей папкой и индексом (или между коммитами). То есть что изменилось, но ещё не добавлено в индекс.
- `git diff --staged` — показывает различия между индексом и последним коммитом. То есть что будет включено в следующий коммит.

## Ветки

Ветка — это подвижный указатель на один из коммитов. Она позволяет вести параллельную разработку, не затрагивая основную линию.

При новом коммите в текущей ветке указатель ветки автоматически перемещается на новый коммит. Другие ветки остаются на своих местах.

Слияние (merge) — объединение изменений из одной ветки в другую. При слиянии создаётся новый коммит слияния (если использовать --no-ff), который объединяет истории обеих веток.
